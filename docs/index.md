# Static Site Generator Lab

Добро пожаловать в документацию лабораторной работы по созданию статического сайта с помощью MkDocs, автоматической публикации через GitHub Actions и деплою на Helios ИТМО.

## Что реализовано

- **MkDocs + Material** — генератор со строгой сборкой (`--strict`)
- **GitHub Actions** — CI/CD пайплайн: lint → build → deploy
- **GitHub Pages** — автоматическая публикация из ветки `main`
- **Helios ИТМО** — деплой по SSH в подкаталог `/ssg`
- **Воспроизводимость** — зафиксированные версии Python и пакетов
- **Кэширование** — замеры времени с кэшем и без
